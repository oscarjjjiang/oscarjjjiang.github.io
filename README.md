# Octopod AI - 智腕人工智能科技官网

## 项目简介

这是智腕AI（Octopod AI）的官方网站，展示公司的产品、解决方案和企业文化。网站采用现代化的响应式设计，支持中英文双语切换。

## 功能特性

### 🌐 双语支持
- 完整的中英文双语切换功能
- 一键切换语言（点击右上角语言按钮）
- 键盘快捷键：`Ctrl/Cmd + L` 快速切换语言
- 所有内容都支持双语显示

### 📱 响应式设计
- 完全适配桌面端、平板和移动设备
- 移动端友好的导航菜单
- 优化的触摸交互体验

### 🎨 现代化UI
- 渐变背景和动画效果
- 悬浮动画和过渡效果
- 现代化的卡片设计
- 优雅的配色方案

### ⚡ 交互功能
- 平滑滚动导航
- 表单验证和提交
- 实时通知系统
- 滚动时的导航栏变化

## 使用方法

### 本地运行
1. 下载所有文件到本地目录
2. 用浏览器打开 `index.html` 文件
3. 或者使用本地服务器（推荐）：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx serve .
   ```

### 部署到服务器
1. 将所有文件上传到Web服务器
2. 确保服务器支持静态文件服务
3. 配置域名和SSL证书（推荐）
